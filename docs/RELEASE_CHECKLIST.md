# Release checklist

- [ ] Scope, threat model, risk and privacy impact reviewed.
- [ ] No secrets or production data in source/tests/artefacts.
- [ ] Dependency, secret and static scans reviewed.
- [ ] SBOM regenerated and archived.
- [ ] Type check, lint, unit, integration, security and migration tests pass.
- [ ] Forward migration tested from the previous schema with backup.
- [ ] Production build succeeds and security headers are verified.
- [ ] Roles/permissions, upload, audit chain, lifecycle, routing and offline sync verified.
- [ ] Model/dataset versions and evaluation evidence recorded.
- [ ] Backup/restore and rollback plan reviewed.
- [ ] Changelog, residual risks, supported versions and operator instructions updated.
- [ ] System Owner, Risk Owner and Data/Model Owner approvals recorded as applicable.
- [ ] Deployment secrets, identity assurance, rate limits, monitoring and retention configured.
- [ ] Post-release monitoring and rollback owner scheduled.
