# Three-minute demonstration script

**0:00–0:20 — Problem.** “Small teams receive English, Nigerian Pidgin, screenshots and incomplete cyber reports. Triage247Ng turns them into privacy-reduced, prioritised records while humans keep control.” Show the independent-platform notice.

**0:20–0:55 — Pidgin intake.** Use the synthetic judge identity. Submit: “Abeg person send link https://verify-pay.example.test, say make I login. My number na 08031234567.” Show detected PII, redacted text, category, confidence, severity factors, indicators and recommended team.

**0:55–1:20 — Duplicate and OCR.** Submit a differently worded version and show its cluster. Upload the synthetic screenshot and show local OCR, privacy scan and suspicious URL.

**1:20–1:45 — Priority and human control.** Open Priority Queue; show Critical at the top. Correct one deliberately wrong recommendation, enter a reason and show the audit event. Confirm that external routing needs Senior Analyst approval.

**1:45–2:15 — Offline.** Disconnect, submit another synthetic report, show its stable local reference and local queue. Reconnect, synchronise once and show duplicate-submission prevention.

**2:15–2:45 — Honest evidence.** Open Analytics: 712 synthetic reports, zero cross-partition cluster leakage, category/language/confusion metrics, OCR results, failures and the redaction recall limitation.

**2:45–3:00 — Close.** “Triage247Ng is an independent, offline-capable, AI-assisted triage layer. It recommends; authorised people decide.”

Backup: if OCR is slow, use the checked-in OCR evaluation and answer key; if the network fails, continue the IndexedDB flow; if hosted identity is unavailable, use the explicit local development identity only on localhost.
