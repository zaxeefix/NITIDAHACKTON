# Production checklist

- [ ] Owner approves official hackathon rules and target accounts
- [ ] Independent security/privacy review completed
- [ ] Production identity, MFA, recovery, expiry and revocation configured
- [ ] Trusted origins, TLS, domains and security headers verified
- [ ] Managed database and durable evidence storage provisioned
- [ ] Encryption, backup, restore, RPO/RTO and retention tested
- [ ] Malware scanner releases evidence from quarantine
- [ ] Secrets and dependency scans pass; SBOM refreshed
- [ ] Migrations and rollback tested on a production-like copy
- [ ] Reporter isolation and all role paths tested
- [ ] Accessibility and responsive tests completed
- [ ] Model/OCR limitations accepted and monitoring enabled
- [ ] No real data, credentials or debug flags in repository
- [ ] Judge access and backup demonstration verified
