# Triage247Ng AI model card

## Model and owner

Model: `triageng-mnb-v1`, an explainable Multinomial Naive Bayes text classifier generated by `ml/triageng_pipeline.py`. The deploying institution must name an AI Model Owner; until then ownership is unresolved.

## Intended use

Recommend incident category, severity and routing evidence for English and Nigerian Pidgin cyber reports. Support prioritization and human analysis.

## Prohibited use

No automatic routing, closure, disciplinary/legal conclusion, attribution, surveillance decision, access denial, or irreversible action. It is not a substitute for analyst judgment, forensic validation or institutional policy.

## Data and limitations

Training/evaluation uses a reproducible synthetic labelled dataset. Synthetic performance is not production performance. Risks include distribution shift, sparse vocabulary, Pidgin variation, adversarial wording, OCR corruption, redaction loss, duplicate errors, confidence miscalibration and severity under/overestimation.

## Evaluation

Preserve accuracy, precision, recall, F1, confusion matrix, critical recall, severity/routing accuracy, indicator/redaction/duplicate metrics, English/Pidgin breakdown, OCR character/word accuracy, confidence, runtime, misclassified cases and failure analysis in checked-in evidence.

## Governance

Model changes require versioned dataset/code/artefact hashes, evaluation comparison, privacy/security review, Model Owner and Risk Owner approval, change log/audit event, rollback artefact and post-release monitoring. Critical and low-confidence cases require mandatory human review.
